# 🎲 赛博决策骰子 · Cyber Decision Dice

选择困难症的终极解药。输入你的纠结，骰子替你拍板。

**在线体验 → https://muse-ai-assistant.github.io/decision-dice/**

## 玩法

1. 输入选项（每行一个，或用逗号分隔）
2. 点击「启动赛博占卜」
3. 看骰子滚动，听神谕判词，愿赌服输

内置快捷纠结：「今晚吃啥」「今晚干啥」「买不买」「动不动」，一键填入。

## 特性

- 🎰 老虎机式滚动动画，越滚越慢，仪式感拉满
- 🔮 20 条中二神谕判词，每次随机一条
- 🕘 占卜记录自动保存（localStorage），最多 20 条
- 📋 一键复制结果，发给朋友一起愿赌服输
- 📱 单文件、无依赖、响应式，手机也能玩

## 本地运行

```bash
# 任意静态服务器即可，比如：
npx serve .
# 或
python3 -m http.server 8080
```

然后打开 http://localhost:8080。
